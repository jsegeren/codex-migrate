Built after the hard version

Your Codex workspace is more than a login.

Signing in on a new Mac does not recreate every piece of local working state. Codex Migrate inventories what exists, moves it over a connection you control, preserves the new Mac's identity, and proves the result before calling it done.

  1. 01

    Inspect

    See exactly what will move, how large it is, and whether both Macs are ready. Planning mode changes nothing.

  2. 02

    Transfer

    Move your workspace over Wi-Fi or a compatible USB-C/Thunderbolt network connection. Both use secure SSH. When both routes are available, Codex Migrate tests them and selects the faster verified connection. Pause and resume without starting over.

  3. 03

    Protect

    Verify a destination backup before replacement. Insufficient space or failed verification blocks installation. Keep an independent backup too.

  4. 04

    Verify

    Compare conversation counts, check databases, and produce a readable receipt of what arrived.

Straight answers

Before you move anything.

Is this made by OpenAI?

No. Codex Migrate is an independent compatibility project. It is not affiliated with, supported by, or endorsed by OpenAI.

Does it copy my Codex login?

No. Authentication and installation identity are deliberately excluded. You sign in on the new Mac first; the migration preserves that new identity.

Can I transfer over Wi-Fi or a cable?

Yes. Use Wi-Fi or a compatible USB-C/Thunderbolt network connection between your Macs; Ethernet works too. The transfer uses secure SSH in each case. After verifying the new Mac, Codex Migrate checks its reachable private network addresses and selects the faster verified route. USB-C cables vary in capability and speed, so the cable setup must provide a working network connection—not just charging. Enable Remote Login on the new Mac, then follow the connection guide.

Can I buy the paid app today?

Not yet. The $50 downloadable Mac edition is in development. We are not taking pre-orders. The complete open-source CLI is usable today.

Does it work on Windows?

Not yet. Codex Migrate currently supports Mac-to-Mac migration only, including the open-source CLI. A Windows version is feasible, but it needs its own work on file locations, permissions, backups, packaging, and recovery testing. Windows and cross-platform transfers are not supported today, and there is no announced release date.

What if the transfer is interrupted?

Rerun it. Staging uses resumable transfer semantics, so completed data is reused. The source Mac is never deleted or modified.

Can I migrate only one thing?

Yes. Personal and repository-scoped skills can already be exported independently; more selective components will use the same guarded workflow.

What support and refunds will be included?

Best-effort support, with an initial response target of a few business days, not a guaranteed fix or service level. When sales open, purchases will have a 30-day refund window. See the refund policy.
